# Reference corpus

This directory contains the durable provenance record for NeoBabylon's
Phase 0 research. The downloaded source, documentation, binaries, and
generated protocol outputs live in the ignored `reference/cache/` directory.

The corpus is evidence, not a runtime dependency and not a license to copy
unreviewed upstream behavior into production. Read [INDEX.md](INDEX.md) for
the selected baseline, coverage, inspection map, and limitations. Read
[sources.json](sources.json) for machine-readable source records and hashes.

## Cache policy

- `cache/codex/rust-v0.155.1/source/` preserves the extracted upstream source
  layout for inspection; it has no nested Git repository.
- `cache/docs/2026-09-22/` contains the official Markdown snapshot used by the
  Phase 0 notes.
- `cache/codex/rust-v0.155.1/protocol-generated/` contains protocol outputs
  generated by the matching Codex CLI with stable and experimental switches.
- `cache/codex/rust-v0.155.1/metadata/protocol-generated.sha256.json` indexes
  every generated contract file.
- `cache/supplemental/` contains comparison-only Astryx and current-main Codex
  captures, plus an explicit unavailable record for the blocked article.

The cache can be recreated with
`pwsh -File scripts/acquire-reference.ps1 -DownloadAppServer -DownloadCodexCli`.
That command is intended for this project directory and does not alter shared
Codex settings or install dependencies.
