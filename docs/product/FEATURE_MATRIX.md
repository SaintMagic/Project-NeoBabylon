## Matrix interpretation

The matrix does not turn every upstream capability into a NeoBabylon promise.
In particular, the presence of a protocol type or source module is not proof
of provider compatibility, safe permissions, UI usability, or packaging
readiness. The build plan converts those gaps into gates and fixtures.
